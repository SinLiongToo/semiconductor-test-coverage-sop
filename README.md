# 跨站測試覆蓋優化 SOP

半導體 WT／FT 跨站測項冗餘分析方法論 — 判斷哪些測項可以從後站移除或降頻抽測，同時給出可交代給稽核的統計依據，而不是憑「幾百顆沒看到 fail」就下結論。

## 內容

- [`跨站測試覆蓋優化SOP.html`](./跨站測試覆蓋優化SOP.html) — 單一自包含 HTML 文件，離線可開，內容涵蓋：
  - **Phase 0 前置強制檢查**：規格／驗證標準強制項目、零覆蓋守則、溫度 corner 移除的前提條件
  - **Phase 1–2**：測試對應矩陣（Test Mapping Matrix）、STDF 資料萃取與 die-level 追溯
  - **Phase 3 統計分析**：Bin-level（屬性資料）、Parameter-level（變數資料）、溫度 Corner 線性（TC 模型）三條證據線，含樣本數公式與推導依據
  - **Phase 4–6**：風險分級（Tier A/B/C）、Pilot 導入與 SPC 監控、正式變更與回退機制
  - 附錄：可直接複製到 Excel 的範本欄位（測試對應矩陣、決策紀錄）、公式參考卡、延伸標準

## 怎麼用

直接用瀏覽器開啟 `跨站測試覆蓋優化SOP.html`，不需要伺服器或安裝任何東西。

頁面右上角有幾個控制項：

| 功能 | 說明 |
|---|---|
| 🌙／☀ Dark / Light | 手動切換深色／淺色模式，預設跟隨系統設定，選擇會記在瀏覽器本機 |
| EN／中文 | 切換全文語言，兩種語言內容都已寫好，不是機器翻譯即時切換 |
| Find / 搜尋 | 站內搜尋，會自動展開被收合的段落並跳到命中處；Enter 找下一筆、Shift+Enter 找上一筆、Esc 清除 |
| 每個標題左側的箭頭 | 點標題可收合／展開該段落內容 |

公式（樣本數推導、Cpk、溫度係數模型）透過 [KaTeX](https://katex.org/)（CDN 載入）排版成教科書風格；離線沒有網路時公式會退回顯示原始 LaTeX 文字，其餘內容不受影響。

## 方法論摘要

核心主張：只看 Bin（Pass/Fail）層級的「零 fail」不足以證明可以安全移除一個測項——那只是二元資料，要把「零事件」轉換成可信的風險上界，天然需要極大樣本數（例如證到 10 DPPM 等級 95% 信心約需 30 萬顆）。必須下探到 Parameter（實際量測值）層級，用相關係數、margin 趨勢、Cpk 站間比較，才能用小得多的樣本數（n≈20–200 等級）建立站得住腳的統計論證，同時看見「兩站都 Pass、但 margin 正在被吃掉」的隱性風險。

三個不可退讓的前提（Phase 0）：

1. **規格／驗證標準強制的測項不可移除**，無論統計結果多乾淨——這是契約/驗證等級的承諾，不是工程風險判斷能覆蓋的範圍。
2. **不可以零覆蓋**：移除的必須是重複的覆蓋，不能是任一參數在整個流程（所有站別 × 所有溫度 corner）中唯一的覆蓋。
3. **溫度 corner 的移除是另一個問題**，不能用跨站相關性代替：必須用至少三個溫度點驗證線性假設本身是否成立（很多參數如漏電流是指數關係而非線性），才能用溫度係數模型推算未測 corner 的風險。
